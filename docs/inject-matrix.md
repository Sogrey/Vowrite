## 1. 测试方法

1. 启动 Vowrite（GUI 或 CLI），确认监听开启、`inject.enabled=true`。
2. 目标应用聚焦到**可编辑输入区**（光标可见）。
3. 按住触发键口述一句短话（或 CLI：`python p0/run_vowrite.py --message "注入矩阵测试一句"`）。
4. 观察文字是否出现在光标处；检查原剪贴板是否在粘贴后恢复（H01）。
5. 每格填：`✅` 成功 / `⚠️` 偶发失败 / `❌` 失败，并在备注写环境与版本。

**建议样例句**：`注入矩阵测试一句，剪贴板应恢复。`

## 4. 已知限制（测试前必读）

| 现象 | 原因 | 处理 |
|---|---|---|
| 管理员窗口粘贴无效 | Windows UIPI | 以同样完整性级别启动 Vowrite |
| 焦点在只读/非编辑区 | 盲贴无落点 | 先点入输入框；失败时结果留在剪贴板（可手动 Ctrl+V） |
| 粘贴后剪贴板仍是注入文 | `restore_delay_ms` 过短或 `restore_clipboard=false` | 调大 delay；确认配置 |
| 杀软拦截键盘钩子 | `keyboard` 全局钩子 | 加白名单 |
